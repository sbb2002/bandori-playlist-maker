# method-2-key

> 상세 근거는 `../DESIGN.md` §2 참조.

## 방식
- **전곡 단일 평균 크로마는 기각** — 후렴 전조가 빈발해 두 키의 혼합이 됨.
- 10–20초 **윈도우별** 크로마(CQT) → Krumhansl-Kessler(1982) 24개 템플릿 매칭.
- 윈도우별 매칭 결과를 **지속시간 가중 다수결**로 대표 키 결정 + **전조 플래그** 기록.
- 교차검증: Essentia `KeyExtractor`(HPCP 기반 별도 알고리즘).
  - "키 자체 불일치"와 "모드만 불일치"를 구분 기록(→ method-3-mode 신뢰도 판단에 사용).
- 통계적 방법, proxy 아님(단 전곡 기준 필수, 45초 발췌 금지).

## 대표값 집계
- 범주형 → 지속시간 가중 다수결. 요약통계 세트 예외 대상.

## 파일럿에서 확정할 것
- 윈도우 길이(10s vs 20s) 및 겹침 여부.
- 전조 판정 임계(다수결 2위 후보와의 지속시간 격차 기준).
