# method-1-tempo

> 상세 근거는 `../DESIGN.md` §1 참조.

## 방식
- **1차**: 온셋 강도 스펙트럴 플럭스 → 자기상관 피크로 BPM 후보 산출.
- **정제**: madmom `DBNBeatTracker`(사전학습 RNN 비트트래킹)로 대체/보정.
- 통계적 방법, ML 아님(madmom도 진짜 목적에 맞는 오픈 모델이라 proxy 아님).

## 대표값 집계
- 전곡 비트 간격 **중앙값** → BPM.
- 범주형 요약통계 세트(중앙값/p10/p90/std) 예외 대상.

## 파일럿에서 확정할 것
- madmom 기본 탐지범위(~55–215BPM) 밖의 고속곡(215BPM+) 옥타브(반절/배속) 판정 정책.
- min/max BPM 설정값.
- 곡 중간 하프타임 구간이 있는 곡의 대표값 처리(플래그 기록).
