# method-4-loudness

> 상세 근거는 `../DESIGN.md` §4 참조.

## 방식
- ITU-R BS.1770 통합 라우드니스(LUFS) — `pyloudnorm`으로 표준 그대로 계산.
  K-weighting 필터 → 채널합산 평균제곱 → 게이팅(절대 −70LUFS, 상대 −10LU) → 적분.
- 통계적/국제표준 구현체, proxy 아님.

## 대표값 집계
- 대표값 = **통합 LUFS**(전곡 게이팅 적분, 윈도우 평균 아님).
- 시계열 = BS.1770 short-term loudness(3초).
- 변동폭 = EBU R128 **LRA**(≈p95−p10) — 요약통계 세트를 자체 발명하지 않고 표준으로 대체.

## 파일럿에서 확인할 것
- 소스 음원의 마스터링·인코딩 일관성 — 플랫폼 라우드니스 정규화가 이미 적용된 파일 혼입 여부
  선행 확인 필수(혼입 시 LUFS 비교가 왜곡됨).
