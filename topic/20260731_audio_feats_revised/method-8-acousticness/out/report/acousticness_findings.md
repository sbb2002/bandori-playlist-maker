### 특징 분석

**상위곡의 특성**:
1. **명확한 패턴**: 상위곡은 대부분 Cover 곡 또는 "Acoustic Ver." 태그 포함 → 모델이 어쿠스틱 편곡은 정확히 감지
2. **밴드별 특성**: mugendai_mutype의 Cover곡(최고 0.987), mygo의 어쿠스틱 곡(0.88~0.76), poppin_party의 Acoustic Ver.(0.90~0.44) 등 일관성 있음
3. **분포 이중성**: 상위 15곡은 0.40~0.99로 넓게 분포하나, 전체의 50%는 1e-4 미만 → "acoustic 신호"와 "non-acoustic"이 명확히 분리된 이중분포
4. **순위 내 그라데이션도 청감상 타당함**: 최상위권(0.9대, 翼をください·Symbol III・STAR BEAT!)은 실제로 생악기 위주 편곡. 반면 순위 하위권으로 갈수록(예: secret base ～君がくれたもの～ (Cover), 0.672) 악기 자체는 전자악기이지만 이펙터로 클린톤을 살려 "어쿠스틱한 감성"만 재현한 곡들이 나타남 — 모델이 "진짜 어쿠스틱"과 "어쿠스틱 느낌의 톤"을 하나의 연속적인 순위 안에서 자연스럽게 그라데이션으로 잡아내고 있다는 뜻으로, 상위 15곡 리스트 자체의 질적 신뢰도는 높다고 판단됨.

## 변별력 평가

### 이중분포 진단
데이터는 **명확한 이중분포(bimodal)** 특성을 보임:
- **집단 1 (주류)**: 49.9%의 곡이 1e-4 미만 (거의 0)
- **집단 2 (acoustic)**: 소수 곡이 0.40~0.99 범위 (명확한 신호)

### 강점
1. **집단 내 일관성**: 상위곡들이 "Acoustic Ver." 또는 "Cover"로 일괄 태그됨 → 모델이 어쿠스틱 신호를 정확히 포착
2. **명확한 경계**: 상위 1곡과 상위 20곡 사이에 0.40 이상의 gap 존재 → 선택적 필터링 가능

### 약점
1. **CV = 5.22**: 극도로 높은 변동계수 → 평균값 기반 처리 불가
2. **중앙값 신뢰도**: 중앙값 1.01e-04는 집단 1의 특성만 반영, 전체 분포 왜곡
3. **coverage 부족**: 전체의 50%에 불과한 중간대(0.001~0.40) 곡 거의 없음 → 세밀한 gradation 불가

### 결론
**제한적이지만 선택적 변별력 有**. "음향 감지" 용도(어쿠스틱/커버곡 필터) 목적으로는 사용 가능하나, 연속적 선곡가중치로는 부적절.

이 IP(밴드시아) 특성상 대부분 곡이 전자악기를 포함한 밴드 사운드일 수밖에 없어
95%가 0~0.05 구간에 몰리는 것 자체는 예상된 결과이며, 데이터 결함이 아니라
장르 구성을 정확히 반영한 결과로 판단됨. 소수의 어쿠스틱/클린톤 이상치 곡을
가려내는 "필터" 용도로만 활용하고, 선곡 가중치 같은 연속값으로는 쓰지 않는다는
결론에 동의.

## 권장사항

1. **용도 제한**: 선곡 엔진의 "모든 가중치" 입력이 아니라, **필터 전용**(예: "acoustic_median > 0.10인 곡 추출")으로 활용
2. **지표 보류 사유**: README.md의 "분포 퇴화 탈출 조건" 부분적 충족 (경계는 명확하나 커버리지 극히 낮음)
3. **청취 스팟체크**: 상위 10~15곡 + 하위 10곡을 실제로 청취해 모델의 경계값(threshold) 재조정 필수
4. **대안 탐색**: 보정 없이는 선곡 우선순위 강등 권고 (energy/mode_score 재정렬 우선)
