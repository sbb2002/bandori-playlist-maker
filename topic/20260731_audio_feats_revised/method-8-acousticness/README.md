# method-8-acousticness

> 상세 근거는 `../DESIGN.md` §8, "분포 퇴화 탈출 조건" 참조.

## 방식
- Essentia 사전학습 `mood_acoustic` 분류기(acoustic/non_acoustic 확률).
- **경(輕) Proxy** — 개념은 거의 일치하나 Spotify 원 모델·라벨셋과는 다름.

## ⚠️ 분포 퇴화 위험
- 카탈로그(661곡)가 거의 전부 스튜디오 녹음 밴드 사운드라 **저값 대역에 몰릴 가능성 큼**.
- 파일럿 단계에 분포 분산·변별력 점검 필수. 강등 판정 기준(IQR 임계, 상위/하위 그룹 청취
  대조 불일치율 등)을 파일럿 사전 등록에 포함.
- 변별력 없다고 판정되면 전수 산출은 하되 **선곡 엔진 투입은 보류**(우선순위 강등).

## 대표값 집계 (정적 피처)
- 기본 대표값 = 중앙값. std는 진단 지표(예: "어쿠스틱 인트로 → 밴드 진입" 구조 신호 → 분포
  퇴화 점검·오탐 청취 대조 시 우선 청취 대상 선정에 활용).
