# method-10-liveness

> 상세 근거는 `../DESIGN.md` §10, "분포 퇴화 탈출 조건" 참조.

## 방식
- **1차**: PANNs(Kong et al. 2020, AudioSet 527클래스 CNN14, 사전학습 오픈) —
  "Crowd"/"Applause"/"Cheering" 클래스 확률 평균.
  **Proxy(명확)** — 관객 소음 이벤트 탐지지 "라이브 공연일 확률" 자체가 아님.
  - ⚠️ **오탐 주의**: 곡 내 함성 이펙트·갱보컬("Hey!" 등)이 Crowd/Applause로 오검출될 수 있음
    → 파일럿에서 상위 검출곡 청취 대조 필수.
- **통계적 보조**: 트랙 전체 노이즈플로어 광대역 에너지 + 잔향 꼬리 길이(RT60 추정).
  **Proxy**(공연장 잔향 근사).

## ⚠️ 분포 퇴화 위험
- 스튜디오 녹음 위주 카탈로그 → 저값 대역 쏠림 가능. 파일럿에서 분산·변별력 점검 필수.

## 대표값 집계 (정적 피처)
- 기본 대표값 = 중앙값. std는 진단 지표.
